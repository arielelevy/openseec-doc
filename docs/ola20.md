# Ola20: alcance y límites

Actualizado: 2026-11-01. Versión del producto: 0.24.0. La integración en main no
equivale por sí sola a una release aceptada ni a cobertura completa.

## Instrucciones de una corrida local

Antes de analizar una carpeta, «Instrucciones de esta corrida» permite excluir
una ruta, registrar una hipótesis o agregar una nota. Se puede agregar y quitar
cada acción. El borrador se fija al enviar y se vacía después o al cambiar carpeta.
No se guarda en el navegador ni se repite automáticamente.

Las hipótesis quedan sin investigar y las notas no se consideran verificadas.
Ninguna instrucción apaga motores ni concede permisos. La API vuelve a validar
el pedido; esta capacidad está deshabilitada en cloud. El resultado terminado
conserva las instrucciones al recargar y abrir el informe guardado.

## Código C# y dependencias

Las reglas C# incorporan fuentes y receptores tipados System.Web para comandos,
LDAP y redirecciones. El caso público de redirección quedó detectado sin cambiar
su oráculo. Son controles DEV, no un holdout nuevo. HttpCookie conserva un falso
negativo condicional porque no se observó su configuración efectiva.

React: 2285 identidades y 185 relaciones directas contrastadas con oráculo independiente.
Las otras 2100 relaciones permanecen desconocidas, sin transitivas confirmadas en esa
medición. Esto no mide vulnerabilidades. Un lockfile YAML multidocumento sigue siendo
no soportado; no se interpreta como cero dependencias ni cero avisos.

La integración CI local conserva códigos 0/1/2 y no ejecuta el repositorio analizado.

## Evidencia acotada de cierre

El formulario verificó 13/13 comprobaciones en navegador con React, API, Python AST
e historia reales, sobre fixtures propias. La localidad30 midió 22 scans y 22
composiciones: AST 14/14 y Opengrep 14/14 equivalentes, sin deriva. No acredita
localidad Roslyn, Gitleaks, OSV ni plataformas no medidas.

Las dos referencias pendientes fueron autorizadas y fijadas sólo después de pasar
sus casos. La aprobación de release requiere además la global y compuerta concluidas;
ninguna prueba focal o captura sustituye ese resultado.

## Prototipos, sin eliminación

La retención OSV sólo planifica. Los leases cooperativos se midieron en Windows y
Ubuntu WSL, pero sus consumidores siguen pendientes de integración. No se acreditó
interoperabilidad de un mismo store entre ambos sistemas ni aislamiento de producción.
El inventario de dependencias declaradas no certifica licencias ni cumplimiento
CycloneDX/SPDX y no realiza evaluación de seguridad.

## Imagen de cobertura

El porcentaje sigue en 88 %: 52 de 59 celdas que aplican alcanzan «Parcial» o mejor.
No es porcentaje de vulnerabilidades detectadas ni probabilidad de seguridad.
C# conserva evidencia histórica; el alcance agregado en SAST15 figura como parcial
porque los controles nuevos son DEV y no tienen un holdout nuevo.

La imagen clara y oscura del README incluye estos límites. Una señal no confirma
una vulnerabilidad y la ausencia de señales no prueba seguridad.
